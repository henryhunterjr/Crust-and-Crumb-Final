- Search and combined filter state are carried in the URL. A term page’s Back to glossary link restores the most recent view in that tab. Related terms use ordinary links. Alphabet availability respects the other filters. Learning paths preserve teaching order when no search is applied.

Initial homepage HTML measured 349,344 bytes on staging, compared with 1,620,814 bytes on the supplied build: approximately 78% less. This is an HTML size comparison, not a Core Web Vitals score. - Added `/editorial-standards`, `/methodology`, `/sources`, and `/updates`. The sitemap contains the home page, four information pages, and 279 canonical term pages. Filtered query views are marked noindex; aliases redirect to canonical terms.
- Expanded Bulk Fermentation, Fresh-Milled Flour, and Underproofed with practical examples, observable cues, distinctions, relevant connections, references, and checked dates. Corrected Whole Wheat Flour and Ash Content. Removed unsupported universal nutrition/freshness wording from the milling promotion. These are AI-assisted source checks, not claims of independent expert review or Henry bake testing.
- Decorative wheat video plays on request. Existing grain photography and click-to-play teaching video work are preserved. Tools use initial focus, a keyboard focus loop, Escape closure, and return focus. Assistant buttons have accessible names and 44-pixel minimum touch targets.
- Updated Next.js to 15.5.27 and patched dependency versions. Production installation and local npm audit both report zero known vulnerabilities at the time of this check. Type checks and production builds pass. ESLint is not configured; no lint pass is claimed.
